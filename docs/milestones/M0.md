pnpm install --frozen-lockfile
pnpm check
node --test fixtures/demo-repo/test/session.test.js
pnpm check:fixture
pnpm check:contracts

The direct demo test is intentionally expected to exit with failure because it reproduces the pinned session-expiration defect. The fixture verifier proves that the failure and repository hashes remain unchanged. All other commands must pass.
