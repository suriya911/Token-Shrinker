- argument-array-only process execution with canonical executable and working-root admission;
- explicit executable and environment allow/deny policy applied before process spawn;
- deadlines, caller cancellation, cross-platform process-tree termination, nonzero exit propagation, and bounded head/tail capture for both output streams;

- migrated pooled SQLite telemetry containing only validated request/provider/token/artifact metadata, with comparable-tokenizer savings, retention, cascading deletion, and integrity checks;

- per-user Unix sockets and Windows named pipes, ephemeral authentication, protected discovery state, single-instance locking, stale-state recovery, readiness publication, bounded concurrent workers, per-request cancellation, graceful drain, and rotating content-free logs.

## Security boundaries

- Commands are never interpreted by a shell and policy denial happens before `spawn`.
- Unix children receive a dedicated process group; Windows children receive a new process group and are terminated through the platform process-tree mechanism.
- Unix runtime directories use mode `0700`, while socket and discovery files use `0600`.
- Windows named pipes use a protected security descriptor for the owner, administrators, and system; every platform also requires an unpredictable 256-bit token read from the protected discovery file.
- Authentication tokens are redacted from `Debug` output and compared without early byte mismatch exits.
- Telemetry accepts only bounded machine labels/enums/counts/hashes and never source, terminal, memory, prompt, or secret bodies.
- Raw output is kept in a distinct expiring store and is never copied into telemetry or lifecycle logs.

## Known risks

- Request handlers must cooperate with their cancellation token; the service raises deadlines and cancellation but cannot safely preempt arbitrary Rust code.
- Raw artifact files are protected by the user runtime/data directory but are not encrypted at rest.
- Built-in terminal classification is deliberately conservative and pattern-based; optional RTK integration remains later provider work.
- The local protocol currently exposes lifecycle, health, capabilities, and test composition methods; the public MCP/CLI method surface is M4.
- Cross-user ACL behavior is enforced by platform primitives; CI supplies Unix and Windows platform coverage, while the local development run covers Windows.
