# M7: extension, evidence, and security review

M7 completes the pre-release product surface without changing an agent's model transport.

## Delivered

- A thin VS Code extension with three SDK-backed commands and explicit workspace-trust gating.
- A minimal VSIX package whose manifest and contents are checked on Windows, macOS, and Linux.
- A deterministic built-ins-only demo with raw JSON and generated Markdown evidence.
- A threat model covering local IPC, repository access, execution, providers, updates, persistence, and the extension boundary.
- Pinned CodeQL, dependency advisory, license, secret, and SBOM workflows.
- Stable-test corpus replay plus `cargo-fuzz` targets for provider version and MCP response parsing.
- A clean-room reviewer packet for native transport, updates, extension trust, security boundaries, and demo evidence.

## Acceptance evidence

The checked-in public demo reports 57.56% comparable-token reduction, 100% required-evidence recall, and 100% citation correctness with every optional provider disabled. The native context builder excludes the synthetic secret canary and identifies the boundary-comparison root cause.

Run the complete milestone gate with:

```text
pnpm install --frozen-lockfile
pnpm check
```

CI repeats the gate on Windows, macOS, and Linux. The security workflow separately runs CodeQL, Rust advisories, dependency/license policy, tracked-file secret scanning, and CycloneDX SBOM generation.

## Release boundary

The VSIX is an engineering artifact, not yet a marketplace release. M8 must obtain the human sign-off described in `docs/reviews/M7-independent-review.md`, verify registry ownership, produce signed release artifacts, and freeze compatibility before `v1.0.0`.
