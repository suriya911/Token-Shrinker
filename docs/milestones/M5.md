# M5 completion report

M5 adds reversible project adapters for Claude Code, Codex, Gemini CLI, OpenCode, and Aider while preserving every agent's native model transport.

## Delivered

- Shared typed detection, dry-run planning, transactional apply/rollback, ownership checks, idempotent reinstall, and scoped uninstall.
- JSON subtree ownership for Claude, Gemini, and OpenCode; a marked TOML block for Codex; owned sidecars for Aider.
- One evidence-preserving skill workflow adapted to each agent's documented project skill directory.
- Live MCP validation through the native stdio server using `capabilities` and `build_context`.
- Content-free `doctor` diagnostics for provider base-URL overrides and wrapper recursion, including Claude Remote Control eligibility.
- Committed adapter fixtures for existing, malformed, partially configured, path-with-spaces, and Windows/macOS/Linux states.

## Safety evidence

- Adapter plans cannot modify configuration outside their exact MCP path or owned fragment.
- Provider endpoint and credential environment variables remain byte-identical during every lifecycle test.
- Claude remains MCP-only: no Anthropic endpoint or credential is written, and `/rc` eligibility is reported false when an external override is detected.
- Skills require user approval before execution and restrict concise formatting to the final human response without dropping warnings, citations, commands, exact errors, or uncertainty.
- Modified owned values are not overwritten or deleted.

## Verification

- 80 Rust tests pass, including native-transport doctor diagnostics.
- 15 Node tests pass across the SDK, launcher, shared adapter core, and five agent packages.
- Five live adapter paths start the real MCP binary and invoke `capabilities` plus `build_context`.
- Native npm package install/smoke/uninstall remains part of the full gate.

## Known limits

- Aider has no native MCP client in its documented configuration surface, so its adapter uses an explicit owned `--config` file and read-only exported context.
- Agent CLIs other than the locally available Claude Code and Codex are contract-tested with fixtures; release qualification should add optional live version probes when those executables are installed.
- JSON configuration is reserialized on a real change, while unrelated values remain structurally identical. Reinstall is byte-stable.

M6 adds optional Graphify, Headroom, RTK, Claude-Mem, and generic MCP memory providers behind the M4 capability/fallback interfaces.
